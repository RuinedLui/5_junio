# Proyecto Final — Módulo Pandas
### Caso: Campaña Snacks × Mundial FIFA 2026 — Guatemala

Proyecto integrador de limpieza, transformación y análisis de datos con Python y Pandas, basado en una encuesta de mercado de 2,500 respuestas sobre hábitos de consumo de snacks en Guatemala durante el Mundial FIFA 2026.
